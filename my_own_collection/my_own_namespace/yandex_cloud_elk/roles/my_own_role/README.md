My_own_role
=========

Ansible-роль для запуска my_own_module

Переменные используемые ролью
-----------------------------

| Переменные | Описание |
|---------------|-----------------|
|      path      | Путь для создания файла |
|    content     |    Наполнение файла     |

Пример использования роли
-------------------------

    - hosts: localhost
      roles:
         - my_own_role
