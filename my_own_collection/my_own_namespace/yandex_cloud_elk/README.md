# Ansible Collection - my_own_namespace.yandex_cloud_elk

My_own_namespace.yandex_cloud_elk
=================================

Данная коллеция содержит плейбук (playbook_my_own_role.yml) который использует роль (my_own_role) в которой задействован модуль (my_own_module.py) для создания текстового файла по заданному пути.

Переменные используемые ролью в коллекции
-----------------------------------------

| Переменные | Описание |
|---------------|-----------------|
|      path      | Путь для создания файла |
|    content     |    Наполнение файла     |

Пример playbook для запуска роли
--------------------------------

    - hosts: localhost
      roles:
         - my_own_role
